Rounds vs blocks

Block = one part of your routine (reps, timed, boxing or rest). Blocks run top to bottom.

Round = all blocks once. Rounds repeats that whole list.

Rest after block (in a block) = pause after that block, in every round.

Rest between rounds = pause after each round, except the last one.

Continue = Auto-start goes straight on. Tap: rounds only waits before each next round, Tap: every block before each next block; rests still run by themselves first. Tap the circle to go on. See the structure below for exactly what happens.

What is count length?

How long one count of a move takes: one count in a rep block, one punch/move in a boxing block. Blocks with an empty count length use this value. Rests, breathers and timers always use real seconds.
